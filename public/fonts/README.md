# Resume display font

`noto-serif-tc-resume.ttf` is a glyph subset of the locally installed Noto Serif TC variable font. The original font copyright notice is © 2017–2023 Adobe. The font is licensed under the SIL Open Font License 1.1; see [OFL.txt](./OFL.txt). The subset includes characters used by the two resume routes and keeps the original variable weight axis.
